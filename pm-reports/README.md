# pm-reports

Temporary project reports live here. Each report is a standalone HTML file
with a simple JavaScript password gate.

Notes:
- This folder is on the PUBLIC website: the JS gate keeps casual visitors
  out but is not real security. Never put client addresses, costs, or
  internal notes in these reports — only non-sensitive summaries.
- Report pages carry `noindex` so search engines skip them.
- Reports are temporary: delete the file when it is no longer needed.
